1 The problem

A server can price a resource. There's no ordinary way for an autonomous agent to pay for it — no card, no checkout page, no human present when the request happens.

HTTP has had a status code for this since 1997: 402 Payment Required. This demo uses it for real. The mechanism is x402, an open protocol built on 402: the server states a price, the agent signs a payment authorization, and a settlement happens on a public ledger.

This runs on Base Sepolia, a free practice copy of a real blockchain, with testnet USDC — worth nothing. The signature, the on-chain settlement, and the balance change are all real; only the money is fake.

2 The demo

A private key is normally the one thing you never publish — whoever holds it can spend the funds. This demo's key is public (reference/charge-agent.json) because the funds behind it are testnet USDC, worth nothing. That means you can use this exact key to sign and send a real payment yourself, instead of taking this page's word for it — see §4.

    3 Test it from your own tools

    The console above is a convenience. The gateway is a plain public HTTP API.

    A — See the price, nothing to install

    curl -i https://eleviq-lab-gateway.gateway-worker.workers.dev/api/charge/report

    Returns 402 with the exact x402 payment requirements — price, asset contract, network, and where payment goes.

    B — Complete the payment yourself (Node.js 18+)

    Completing it needs an EIP-712 signature over an EIP-3009 transferWithAuthorization message — real wallet cryptography, not a curl flag.

    mkdir charge && cd charge
npm init -y && npm install viem

curl -O https://lab.eleviq.solutions/reference/charge-pay.mjs
curl -O https://lab.eleviq.solutions/reference/charge-agent.json

node charge-pay.mjs --tier standard

    charge-pay.mjs is ~50 lines: fetch the price, sign a transferWithAuthorization authorization for it with viem, resend with that signature base64-encoded in an X-PAYMENT header. Same steps this page's own console runs.

    Try --tier premium to see the same insufficient-funds decline as the console's second scenario.
