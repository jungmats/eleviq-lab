2 Where this data comes from

Every request to /api/identity/price-list (Demo 1) is written to a Cloudflare D1 table (access_log) by the gateway itself — see gateway/schema.sql. This page just reads it, via a public endpoint (GET /api/log) that returns a summary and the last 100 rows. Small, demo-scale dataset; the same mechanism is what you'd build for a customer at real volume.

This endpoint is deliberately public, like the rest of the lab — nothing in it is sensitive (it's outcomes and identity claims from a public demo API). A real customer deployment would put a path like this behind Cloudflare Access — identity-aware auth at the edge — rather than building authentication into the dashboard itself. That needs the gateway on a domain we control, which lands once the eleviq.solutions migration this lab is also using is complete; not done here yet.
