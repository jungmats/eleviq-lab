2 Where this data comes from

Every HTML response from eleviq.solutions is logged by a transparent Worker (site-logger) that sits in front of the site — it fetches the real page and returns it completely unchanged, and separately writes one anonymous row per view: page, a visitor category, which AI assistant referred the click (if any), and country. No cookies, no visitor id, no raw IP.

The category comes from the User-Agent string, matched against known signatures (the same taxonomy Cloudflare's own AI Crawl Control uses):

Agent
a specific person asked an AI assistant something right now, and it fetched this page live to answer — ChatGPT‑User, Claude‑User, Perplexity‑User, and similar. This is the attribution signal: a real request on someone's behalf, not background crawling.
Human
looks like an ordinary browser, no known agent signature.
Search
indexing crawlers — Googlebot, Bingbot, OAI‑SearchBot, and similar.
Training
bulk crawlers that train models — GPTBot, CCBot, and similar. Not tied to any one person's request.
Unrecognized
doesn't match a known signature and doesn't look like a browser either — most often a home‑grown or unlabelled agent (a bare HTTP client's default User-Agent, e.g. python-requests or curl).

The honest limit: this is a heuristic, string-matched signal — the same kind request.cf.verifiedBotCategory is, not a cryptographic proof (see Demo 1 for what a real proof looks like). A UA that deliberately claims to be a normal browser is indistinguishable from a normal browser by this method, full stop. All five categories are logged for now, deliberately — nothing is filtered out yet.

This page shows real production traffic to eleviq.solutions, unlike Demo 1's own access log (public, demo-only data) — so it sits behind Cloudflare Access at the edge rather than being left open.
