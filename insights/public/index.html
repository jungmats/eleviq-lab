2 Where this data comes from

Every HTML response from eleviq.solutions is logged by a transparent Worker (site-logger) that sits in front of the site. It returns the page unchanged and separately writes one anonymous row per view: the page, the signals that identify the visitor, which AI assistant referred the visit (if any), and the country. No cookies, no visitor id, no IP address, and no browser User-Agent string.

Each visit is sorted into a kind (people, AI assistants, search, AI training, other bots, unidentified) and, where there is evidence of who the visitor is, an evidence level. The i buttons next to the filters explain each kind, each level, and what this method cannot see.

The classification runs when this page loads, over the stored signals, so older visits are shown with the same rules as new ones.

This page shows real production traffic to eleviq.solutions, so it sits behind Cloudflare Access.
